# 📊 Superstore Sales Analysis Dashboard | Excel

## 📌 Project Overview

The **Superstore Sales Analysis Dashboard** is an Excel-based data analytics project designed to analyze sales performance, profitability, customer segments, product categories, and shipping trends.

The project uses the Superstore dataset to transform raw sales data into meaningful insights through Excel formulas, Pivot Tables, and an interactive dashboard. It helps users understand business performance and make data-driven decisions.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify profitable product categories and sub-categories.
- Understand sales trends across years, months, and quarters.
- Compare customer segments and regional performance.
- Analyze order quantities, discounts, and shipping methods.
- Present key business insights through a visual dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables

- Data Analysis and Reporting
- Interactive Filters and Slicers, where configured

## 📂 Project Structure

The Excel workbook contains three worksheets:

| Worksheet | Description |
|---|---|
| `Superstore` | Raw sales dataset containing order, customer, product, shipping, sales, discount, and profit information. |
| `Pivat Table` | Summary metrics and Pivot Table-based analysis for reporting. |
| `Dashboard` | Visual representation of sales performance and business insights. |

## 📈 Key Performance Indicators (KPIs)

The workbook summarizes the following key business metrics:

- **Total Sales:** Overall revenue generated from orders.
- **Total Profit:** Total profit earned from sales.
- **Profit Margin:** Percentage of sales retained as profit.
- **Total Quantity:** Total number of product units sold.
- **Total Orders:** Count of order records, with distinct orders requiring a unique Order ID count.

### Dataset Summary

- Total records: 9,994 sales transactions
- Total sales: Approximately $2.30 million
- Total profit: Approximately $286,397
- Total quantity sold: 37,873 units

*These figures reflect the workbook's summary values and may depend on the formulas and filters applied.*

## 🧮 Excel Functions Used

The workbook includes formula-based calculations such as:

- `YEAR()` — Extracts the year from an order date.
- `TEXT()` — Formats dates to display month names.
- `ROUNDUP()` — Helps calculate quarterly labels.
- Basic arithmetic formulas — Calculates profit margin and summary metrics.
- Pivot Tables — Summarize and compare large datasets.

## 🚀 How to Use This Project

1. Download or clone this GitHub repository.
2. Open `parivartan.xlsm` in Microsoft Excel.
3. Enable macros only if you trust the workbook and its source.
4. Navigate to the `Dashboard` worksheet to view the visual report.
5. Explore the `Pivat Table` worksheet to review summarized data.
6. Use available filters or slicers to explore different business dimensions.
7. Review the `Superstore` worksheet to understand the underlying dataset.

**Note:** The `.xlsm` file supports Excel macros. If the dashboard uses VBA automation, save the workbook in macro-enabled format and enable macros only from a trusted source.
